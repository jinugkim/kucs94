# KUCS 94 경조사 진행 절차 및 상부상조 포털 (kucs94)

고려대학교 컴퓨터학과 94학번(KUCS 94) 동기회 및 동문들을 위한 체계적인 경조사(조사·장례, 경사·결혼, 수연, 출산 등) 진행 절차, 조문/하객 예절, 봉투 서식 작성기, 모바일 알림 생성기 및 동문회 지원 규정 안내 시스템입니다.

---

## 📌 주요 기능 (Key Features)

1. **장례(조사) 진행 절차 & 조문 예절 가이드**
   - 3일장 타임라인 (1일차: 임종·빈소·부고 / 2일차: 입관·조문·제례 / 3일차: 발인·영결·장지·삼우제)
   - 상주(유족) 행정 및 준비물 체크리스트
   - 동문 및 조문객 복장, 분향/헌화법, 재배/묵념, 종교별 예식 차이
   - 삼가야 할 실례와 올바른 위로의 말

2. **결혼(경사) 진행 절차 & 하객 예절**
   - D-180부터 D-Day까지 결혼 준비 타임라인
   - 표준 결혼식 10단계 식순 해설
   - 하객 복장, 축의금 접수대 에티켓, 동문 참석 요령

3. **기타 경조사 가이드**
   - 수연(환갑·칠순·팔순) 절차 및 감사패
   - 출산 및 첫돌(돌잡이 용품의 의미)
   - 승진·영전 및 개업 축하 예절

4. **인터랙티브 경조사 봉투 시뮬레이터**
   - 조의금(賻儀, 謹弔, 追慕 등) 및 축의금(祝婚姻, 祝華婚, 祝結婚, 祝壽宴 등) 서식 선택
   - 앞면 한자/한글 표기 및 뒷면 좌측 하단 이름·소속(고려대 컴퓨터학과 94학번) 실시간 렌더링
   - 앞/뒷면 뒤집기 및 인쇄 지원

5. **부의금 / 축의금 스마트 계산기**
   - 관계(동기, 절친, 선후배, 직장동료), 참석 및 식사 여부, 교류 빈도를 반영한 적정 금액 추천 및 예절 팁

6. **원클릭 모바일 알림 및 답례문 생성기**
   - 부고 알림장 (카카오톡 / 문자 최적화 포맷)
   - 모바일 청첩 / 결혼 알림문
   - 장례 후 조문 감사 답례문 / 결혼식 후 감사 답례문
   - 원클릭 클립보드 복사

7. **KUCS 94 동문회 경조 지원 규정 및 신청**
   - 경조금 지급 기준표 (본인 결혼, 부모상, 빙부모상 등)
   - 고려대 컴공 94학번 근조기 및 축하 화환 신청/배송 프로세스
   - 동문 경조사 등록 및 공지 피드 (로컬 저장소 연동)

## 🚀 빠른 시작 (Getting Started)

### 설치 및 로컬 실행

```bash
# 리포지토리 클론
git clone https://github.com/jinugkim/kucs94.git
cd kucs94

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide React Icons
- **Animation**: Motion (Framer Motion)
- **Tooling**: Vite 8, Node.js

## 📦 GitHub 저장소 연동 가이드

현재 원격 저장소(`origin`)가 `https://github.com/jinugkim/kucs94.git` 로 설정되어 있습니다.

```bash
# 1. GitHub 개인 액세스 토큰(PAT) 또는 SSH 인증 후 푸시
git branch -M main
git push -u origin main

# 2. 또는 GitHub CLI 사용 시
gh repo create kucs94 --public --source=. --remote=origin --push
```
